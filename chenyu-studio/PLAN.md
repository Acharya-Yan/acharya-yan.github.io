# 工作室：分层漫画空间

更新：2026-10-24。按用户最新要求，回到已认可的 2.5D 漫画方向。上一版模型计划保存在 docs/PLAN-character-study.md，仅作历史记录。

## 视觉与空间

保留已认可的白底黑线人物与桌搭。人物坐在桌前、背靠桌搭、面对抬高的三脚架相机，摄影灯在侧面。不再以程序化人物模型替换漫画稿。

四个原始对齐图层分别放在不同深度：桌搭、摄影灯、人物、前景相机。正面时还原原图，移动时产生透视压缩、遮挡变化和不同幅度的位移。人物下方增加柔和接触阴影。插画只表达已有正面，不生成或声称存在真实背面。

## 镜头与交互

- 水平角度限制为 ±12°，俯仰 ±3°。鼠标拖动控制，滚轮缩放范围 0.9–1.85。
- 镜头带阻尼。可选择空间全景、相机视角、桌面视角；自动轻摇限制在 ±9°。
- 点击人物、主屏幕、笔记本分别打开关于我、作品、文字笔记，同时镜头靠近。前景设备在详情状态淡出，避免遮挡。
- 右侧详情是实际 HTML 内容；关闭或 Esc 回全景，恢复可操作焦点。另有等价文字导航与键盘控制。
- 摄影灯开关改变整体明暗，不模拟不存在的实时灯光计算。
- 保留加载、资源失败与静态回退入口。减少动态效果偏好下取消镜头缓动；后台标签暂停动画。

## 技术

继续用 Astro + React。空间引擎位于 src/lib/space/illustrated.ts，使用 CSS perspective、preserve-3d、translateZ 和 requestAnimationFrame，实现具有实际深度排列的插画平面。正面通过透视补偿保证原图层对齐。

此路由不加载 Three.js、GLB 或旧角色模型。停止动画时不持续渲染。图片约 1.4 MB，不新增大型模型资产。内容仍走现有作品与笔记页面。

## 保留范围

原版首页 / 保留；新的 /space/ 替代原实验空间的显示实现。旧 scene.ts、设备模块与独立 character-study 保留为实验源文件，不进入新空间。此阶段仅电脑端，不部署，不采购或上传人像到外部建模服务。

## 当前确认范围

已实现上述交互并检查桌面画面、角度限制和人物/屏幕入口。用户下一步主要评估：漫画形象是否回到认可的风格，以及有限环绕的空间感是否合适。后续如需更大角度，需要补绘原图不可见部分，而不是直接放宽视角限制。
