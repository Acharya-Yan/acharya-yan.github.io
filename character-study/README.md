# 严晨宇 · 独立人物模型 V1

2026-10-24。根据已有正面照片及先前认可的漫画方向制作；未新增照片，侧面、背面和坐姿采用风格化补全。

## 查看

打开 http://127.0.0.1:4332/ ，拖动环绕，滚轮缩放。底部可切换正面、45°、侧面、背面和面部特写，支持自动旋转、素模显示。

若查看器没有运行，在本目录执行：

```sh
python3 -m http.server 4332 --bind 127.0.0.1
```

## 实际资产

- `chenyu-character.glb`：真实网格与材质，可导入 Blender 等支持 glTF 的软件。所有视角来自同一模型。
- `source/avatar.ts`：可编辑的参数化模型源代码；不是 Blender 手工雕刻工程。
- `export.mjs`：生成 GLB 的脚本，复用旁边 chenyu-studio 的 Three.js 和 TypeScript 依赖。
- `previews/`：从独立查看器捕获的实际模型画面。

这是用于外观确认的静态坐姿模型，未做骨骼绑定，尚无可移植的眨眼/肢体动画。头发、面部、眼镜、手指、衣物和鞋均为三维几何。模型不包含用户照片贴图，也没有向第三方建模服务上传照片。

本版本在独立目录制作，没有替换网站中的人物。用户确认后才考虑网页集成、减面、角色绑定及动作。
